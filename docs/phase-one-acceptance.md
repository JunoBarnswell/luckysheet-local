# 第一阶段实施与验收记录

本记录对应 `codex/local-usable-foundation` 的阶段性实现。九项计划仍在推进；下列静态检查与局部行为证据不代表正式交付验收完成。

## 本轮实现边界

- React 浏览器通过 Java 同源 API、会话和 WebSocket 访问工作簿；H2 是持久化权威，IndexedDB 只记录待确认操作。
- 本地管理员初始化、账号登录和管理；本地认证与 OIDC 显式互斥。操作按客户端会话作用域去重，损坏和版本冲突返回错误。
- 原生资源读取验证长度与 checksum，中文文件名使用 UTF-8 `filename*`；大文件导入同时配置 multipart 和表单上限。
- 开始工具栏收紧分组宽度、统一按钮排布；窄窗口使用原有命令的折叠菜单。移除工具栏下方多余固定高度。
- 列标题与数据行分别占用 PaneMap 确定的区域；公式栏和网格编辑框按编辑会话的 surface 分配焦点，非活动编辑框不得抢焦点或修改光标。
- 去除 Electron 生产入口，构建统一 Node 24、JDK 21；前端产物进入 Maven 生成目录。提供 WinSW/NSIS 与备份恢复脚本。

## 工具栏与行列扩展追加验收

- 八个常规选项卡统一高度、按钮尺寸与分组菜单；移除插入页 1905px 最小宽度，并按可用宽度保留所有分组入口。1186px 和 1480px 已逐页检查，无横向溢出或控件越出分组边界。
- 下拉菜单按实际视口限制位置；嵌套菜单保留父菜单所有权，避免子菜单点击前被关闭。折叠插图组 → 形状 → 矩形已执行真实命令并收到保存确认。
- 普通滚轮、滚动条和拖拽选区共同调用 `sheet.extent.grow`；删除 Canvas 自行补到 200 行/26 列的独立尺寸，渲染与编辑使用同一规范边界。失败时恢复在途请求标记，断线或无写权限不新增扩展操作。
- 浏览器验证：1000 行 → 2000 行、26 列 → 130 列，AZ1500 中文编辑保存后刷新，尺寸和内容均保留；普通滚轮继续增长到 3000 行。对应 HTTP 操作提交 201、checkpoint 200；提交前结果查询的 404 表示该稳定操作 ID 尚未提交。
- 工作表按 1000 行/26 列分块增长，上限为 1048576 行、16384 列。该上限来自工作簿模型及 XLSX 边界，不宣称数学意义上的无限。
- 构建与边界检查通过；未运行前端单元测试。后端扩展成功、缩小拒绝与超上限拒绝已包含在前述 112 项测试中。本次变更未修改后端 reducer。
- 动态构建目录替换期间曾使旧标签页的懒加载资源失效，稳定构建刷新后复核成功；不将该次热替换失败记为通过。独立验收服务改用 `localhost:8083`，与用户入口 `127.0.0.1:8082` 隔离登录 Cookie。
- GitHub PR #336 保持 Draft；初次检查未报告远端 checks，不能将“无 checks”记作 CI 通过。
- 会话失效后的真实恢复暴露了权限初始化顺序缺陷：现在先应用服务器权限，再重放已持久化操作；提交失败暂停新增编辑，计算完成不得覆盖失败状态。新版内嵌 JAR 上恢复日志中的操作提交后，原工作簿从版本 7 前进到 10，并显示已保存；未丢弃待确认操作。

- 5 万行 × 20 列、百万非空单元格和 1 万公式的计时、帧耗时与峰值内存。
- NSIS 下载曾返回非安装包内容，被 checksum 校验拒绝；安装程序构建及首次安装、开机启动、升级、卸载保留数据和重装尚未通过。

## 迁移与回滚

客户端会话操作序号及快照版本升级在 Flyway 迁移边界执行；运行时拒绝未知版本，不保留双写或旧版读取作为恢复手段。损坏原生资源不返回空工作簿。IndexedDB 待确认操作必须先持久化，服务端确认并完成 checkpoint 后才清理。

升级前停止服务并使用备份脚本保留数据库、配置与相关数据。回滚整体恢复旧程序和升级前数据库备份；不得让旧程序读取新版数据库。正式部署与安装验收通过前，PR 保持 Draft。
