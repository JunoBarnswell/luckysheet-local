# 万 / 亿数字格式（`w` / `W`）扩展

LuckySheet 在 `frontend/src/global/format.js`（约 1435–1549 行）实现了 **`w` / `W` 万、亿中文单位**。这是 LS 扩展 pattern，不是 Excel `fa` 标准格式，也不是 Univer `@univerjs/sheets-numfmt` 的内置 pattern。

## 行为

| pattern | 显示语义 | 示例（`v = 22500`） |
|---|---|---|
| `w` | 按万/亿拆分，整数部分带「万」「亿」 | `2万2500` |
| `w0` | 同上，整数精度约定 | `2万2500` |
| `w0.0` | 保留 1 位小数 | `2万2500.0` |
| `w0.00` | 保留 2 位小数 | `2万2500.00` |
| `W` | 与 `w` 同类，大小写均识别 | 同 `w` |

实现会把绝对值按 `1亿 = 10^8`、`1万 = 10^4` 拆开，再拼回中文单位字符串。`亿0万` / `万0` 等中间零会被收掉。

## 与 Excel `fa` 的差异

- Excel 官方自定义格式没有 `w`/`W` 万亿语义。Excel 常见的是 `#,##0`、`0.00E+00`、`¥#,##0` 等。
- 把带 `w` 的工作簿用标准 Excel 打开时，该 format code **不会**按「万/亿」显示，通常被当成非法或不识别的 format。
- Univer OSS numfmt 按 Excel 语义解析 `IStyleData.n.pattern`，**不会**实现 `w`/`W`。回移时必须把 `ct.fa` 含 `w`/`W` 的单元格当作 **LS 扩展层** 保留，禁止在 adapter 里改写成 `0.00E+00` 或 `#,##0`。
- 导出到真实 xlsx 时，若目标引擎不认识 `w`，应继续用 `m`（已算好的显示值）兜底，或声明 fidelity 缺口。

## 兼容约束

- 不删除、不改名现有 `w`/`W` 分支。
- `autoFormatw` 配置仍可触发万单位自动打印。
- 科学计数法边界（`#7163`）与空格式 `coverable:false`（`#7383`）不得覆盖 `w`/`W`：万亿格式不是 scientific，空 `fa` 不能盖掉已有 `w`。
